# Meal-4-All 🍽️

Meal-4-All is a web application that helps users plan healthy and affordable meals using the ingredients they already have or by scanning their grocery bills. The app generates practical meal suggestions that are easy to cook, budget-friendly, and suitable for households.

---

## What this project does

- Generates meal plans based on available ingredients, family size, and region
- Suggests breakfast, lunch, and dinner with clear cooking steps
- Estimates meal cost in Indian Rupees
- Highlights basic nutritional benefits
- Reduces food waste by prioritizing existing groceries

---

## Key Features

### Smart Meal Planner
- Enter ingredients, family size, and region
- AI generates meal suggestions for the day
- Each meal includes:
  - Step-by-step cooking instructions
  - Ingredient list with tags
  - Nutrition highlights
  - Cost estimate (₹)
  - Star ratings based on nutrition, ease, budget, and taste

### Grocery Bill Scanner (Hidden Feature)
- Upload a photo of a grocery bill
- Automatically extracts items using AI vision
- Supports dietary preferences (veg / non-veg / vegan / egg)
- Considers health goals like weight loss or muscle gain
- Generates meals using only scanned items
